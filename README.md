# 🦖 Jw2Launcher — Jurassic War 2: The Ranker 런처 & 관전 오버레이

**쥬라기 워2(더 랭커)** 를 위한 통합 런처입니다. 게임 실행부터 **관전·리플레이 실시간 전술 오버레이**, **리플레이 자동저장·전적 연동**, **자동 업데이트**까지 한 번에 제공합니다.

> 📥 **다운로드는 [Releases](../../releases) 탭에서** 최신 `Jw2Launcher_vX.X.X.exe` 를 받으세요.

---

## ✨ 주요 기능

### 🎮 게임 실행
- 넓은 시야(1024×768) / 기본 시야(640×480) / 맵 에디터 실행
- 게임 경로 **자동 감지**, 창모드 해상도·중앙 정렬 등 편의 옵션

### 👁️ 관전 · 리플레이 오버레이 *(관전/리플레이 재생 시에만 표시 — 직접 플레이 중엔 안 뜸)*
- **미니맵 3단계 시야** — 현재 보임 / 탐사됨 / 미탐사 구분 표시
- **확장 전술맵 (A)** — 대형 미니맵 + 좌·우 플레이어 패널 + 상단 HP 대결바
- **전투 액션 모드 (S)** — 상단 HP·인구 게이지 + 죽은/산 유닛 격자 + 마법 시전 표시
- **유닛 상세 툴팁** — 선택한 유닛·건물의 스탯·스킬·업그레이드·생산 카탈로그
- **실시간 비교 게이지** — 두 플레이어 지표를 실시간 대결 게이지로 비교
- **완성 임박 팝업**, **보조 영역(Q~T)** 등

### 💾 리플레이 자동저장 · 전적
- 게임이 끝나면 **리플레이 자동 저장** (저장 버튼 불필요) → `Replays\자동저장\`
- 승패가 갈린 내 게임은 **전적 사이트([jw2-arena.com](http://jw2-arena.com/all))에 자동 기록**
- 무승부·관전은 로컬 저장만 (업로드 제외)

### 🔄 자동 업데이트
- 실행 시 새 버전을 자동 확인 → 있으면 알림 → 클릭 한 번으로 최신 exe 다운로드

---

## 🚀 설치 & 사용법

1. [Releases](../../releases)에서 최신 `Jw2Launcher_vX.X.X.exe` 다운로드
2. **게임 폴더**(`RankerOCPV_Win`)에 넣고 실행
3. 런처에서 원하는 모드로 게임 실행 — 끝!

관전/리플레이를 볼 땐 오버레이가 자동으로 뜹니다.

## ⌨️ 단축키 *(게임 창 활성 시)*

| 키 | 기능 |
|---|---|
| **넘패드 0** | 관전 UI 켜기·끄기 / 새로시작 |
| **A** | 확장 전술맵 |
| **S** | 전투 액션 모드 |
| **넘패드 1** | 좌우 반전 |
| **Q W E R T** | 보조 영역 (생산중·현재유닛·완료업글·일꾼현황·게임통계) |
| **1 ~ 0** | 실시간 비교 게이지 전환 |
| 미니맵·확장맵 클릭 | 카메라 즉시 이동 |
| 휠 클릭 / 마우스 휠 | 맵 스크롤 |

## 🔒 소스 공개 범위 (안티치트)

이 저장소는 **런처 부분을 공개**합니다. 다만 **게임 메모리를 읽는 오버레이 엔진은 비공개**입니다.

> **왜 일부는 비공개인가요?**
> 오버레이 엔진의 메모리 분석 코드가 공개되면 **맵핵 등 치트로 악용**될 소지가 큽니다.
> 공정한 경쟁을 위해 이 부분은 컴파일된 실행파일 안에만 두고 소스는 공개하지 않습니다.
> (오버레이는 **관전·리플레이 전용**이며, 본인이 직접 플레이하는 중에는 표시되지 않습니다.)

경쟁 게임 도구에서 흔한 방식이며, 안전한 런처 부분은 투명하게 공개해 신뢰를 지향합니다.

## 🛡️ 안전성 (백신 오탐 안내)

이 프로그램은 **Nuitka로 기계어 컴파일**되어 서명이 없는 관계로, 일부 백신이 **오탐(false positive)** 을 낼 수 있습니다. 실제 악성코드가 아닙니다.

- 각 릴리스에 **[VirusTotal](https://www.virustotal.com) 검사 결과 링크**를 첨부합니다 (직접 확인 가능)
- 걱정되시면 릴리스의 exe를 직접 VirusTotal에 올려 확인해보세요
